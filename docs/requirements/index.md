# Requirements Index

This folder contains the business requirements of the system.

Each file describes one business module or feature area.

AI agents must read this file first, then open the relevant requirement document before planning or implementing changes.

## How to Use This Folder

When working on a feature:

1. Identify the related business area.
2. Open the matching requirement file.
3. Read the functional requirements, business rules, validations, and out-of-scope items.
4. Check the relevant architecture document before implementation.
