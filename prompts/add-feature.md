# Add Feature Prompt

Use this prompt when asking the agent to implement a documented feature.

## Prompt

Implement the feature described in:

`docs/requirements/{requirement-file-name}.md`

Follow:

- `AGENTS.md`
- `docs/architecture/overview.md`
- `docs/architecture/backend.md` when backend changes are needed
- `docs/architecture/frontend.md` when frontend changes are needed

Expected output:

- Summary of the requirement.
- Implementation plan.
- Files expected to change.
- Assumptions or open questions.
